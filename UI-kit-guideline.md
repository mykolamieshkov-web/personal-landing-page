| Категория              | Элемент / Модификатор                                       | Описание и назначение                                                                                                                      | Пример использования                                  |
| ---------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| Структура и Слои       | __container                                                 | Главная обертка/ограничитель блока.                                                                                                        | .hero__container                                      |
| __cover                | Фоновая подложка (z-index: 1, absolute, object-fit: cover). | .banner__cover                                                                                                                             |                                                       |
| __content              | Контентный слой поверх задника (z-index: 2, relative).      | .banner__content                                                                                                                           |                                                       |
| __inner                | Внутренняя обертка (если __content уже занят).              | .card__inner                                                                                                                               |                                                       |
| Сетка (Layout)         | __layout                                                    | Вертикальный flex-контейнер (column, центрирование).                                                                                       | .section__layout                                      |
| __layout--row          | Горизонтальный flex-контейнер (row, wrap на планшетах).     | .gallery__layout--row                                                                                                                      |                                                       |
| __list / __item        | Семантические списки и их элементы.                         | .nav__list, .nav__item                                                                                                                     |                                                       |
| Данные (Контент)       | __title                                                     | Заголовки блоков или карточек.                                                                                                             | .card__title                                          |
| __desc                 | Многострочный текст, описание.                              | .product__desc                                                                                                                             |                                                       |
| __price, __value       | Числовые данные (цена, счетчик, вес).                       | .cart__price                                                                                                                               |                                                       |
| __img, __icon          | Контентные изображения (не фоны) и SVG-иконки.              | .feature__icon                                                                                                                             |                                                       |
| __badge                | Визуальные метки (скидки, теги, статусы).                   | .product__badge                                                                                                                            |                                                       |
| Интерактив             | __btn                                                       | Кнопки (отправка форм, вызов модалок).                                                                                                     | .form__btn                                            |
| __link                 | Текстовые ссылки для навигации.                             | .footer__link                                                                                                                              |                                                       |
| __control              | Элементы управления (слайдер стрелки, инпуты).              | .slider__control                                                                                                                           |                                                       |
| Модификаторы Состояния | --active, --closed, --hidden, --disabled, --loading         | Важно: применяются к любому элементу или блоку для изменения его JS-состояния или видимости. Описывают, что происходит, а не как выглядит. | .btn--loading, .dropdown--closed, .menu__item--active |
