

# 🚀 React + Vite 

Этот проект представляет собой современную сборку для быстрой и качественной верстки посадочных страниц на React с использованием SCSS и компонентного подхода.

## 🛠 Команды управления

| Действие | Команда |
| --- | --- |
| **Инициализация проекта** | `npm create vite@latest . -- --template react` |
| **Установка зависимостей** | `npm install` |
| **Установка Sass** | `npm install -D sass` |
| **Запуск Dev-сервера** | `npm run dev` |
| **Сборка (Production)** | `npm run build` |
| **Превью сборки** | `npm run preview` |
| **Очистка кэша npm** | `npm cache clean --force` |

## 📂 Структура проекта (Component-Based)

Мы используем модульный подход: каждый компонент автономен и содержит свои стили.

```text
src/
├── assets/
│   ├── styles/
│   │   ├── _variables.scss   # Переменные (цвета, сетка)
│   │   ├── _mixins.scss      # Твои миксины из стартера
│   │   └── _reset.scss       # Сброс стилей
│   └── images/               # Иконки и дизайн-элементы
├── components/               # Папка для всех компонентов
│   └── HeroSection/          # Отдельная папка компонента
│       ├── HeroSection.jsx   # Разметка (JSX)
│       └── HeroSection.scss  # Стили компонента
├── App.jsx                   # Главный контейнер
├── main.jsx                  # Точка входа (React DOM)
└── index.scss                # Глобальные стили (импорт шрифтов)

```

### Где подключать SCSS?

1. **Глобально:** В файле `src/main.jsx` импортируй `import './index.scss'`. Внутри него подключай `_reset.scss`.
2. **Утилиты:** Внутри каждого `Component.scss` используй `@use 'path/to/mixins' as *;`.

## 🛡 Безопасность (Декабрь 2025)

На текущую дату (декабрь 2025) наиболее стабильными и защищенными являются версии **React 18.3+** и **React 19**.

* **Важно:** Всегда используй команду `npm audit` для проверки зависимостей на уязвимости.
* Основная защита в React встроена на уровне JSX — он автоматически экранирует данные, защищая от XSS-атак.

## 💨 Преимущества Tailwind CSS

Если ты решишь добавить Tailwind в свои будущие проекты, ты получишь:

1. **Скорость:** Тебе не нужно переключаться между файлами `.jsx` и `.scss`. Все стили пишутся в `className`.
2. **Минимальный размер CSS:** Tailwind генерирует только те стили, которые ты реально использовал.
3. **Дизайн-система:** Встроенные отступы и цвета не дают тебе "накосячить" с дизайном.

## 📈 Перспективы на 2026 год

Освоив этот стек (React + Vite + SCSS/Tailwind) к началу 2026 года, ты сможешь:

* **Создавать сложные SPA (Single Page Applications):** Не просто лендинги, а личные кабинеты, дашборды и маркетплейсы.
* **Работать в команде:** Твой подход к папке `components/` — это стандарт индустрии. Любой разработчик поймет твой код.
* **Зарабатывать больше:** Верстальщик на React ценится в 1.5–2 раза выше, чем классический верстальщик на HTML/CSS, так как он может брать на себя логику интерфейса.
